PASO 1 DE 4

Verifica que tu equipo cumple

Sistema operativoWindows 10/11 o macOS 12 en adelante
Memoria RAM8 GB recomendado (4 GB mínimo, va más lento)
Espacio libre en disco2 GB o más
PermisosPoder instalar programas (tu usuario o el admin)
InternetWiFi funcional (en el taller hay red)

Descarga el verificador para tu sistema y córrelo — te dice en 10 segundos cómo está tu equipo:

⬇ Verificador para Windows ⬇ Verificador para Mac

  • Windows: doble clic en verifica.bat. Si Windows pregunta, elige "Ejecutar de todas formas".
  • Mac: abre la app Terminal, escribe bash, un espacio, arrastra el archivo verifica.command a la ventana y presiona Enter.
¿Tu equipo no cumple o el verificador marca algo raro? Mándanos la captura por WhatsApp: la revisión y el diagnóstico son gratis. Si tu equipo necesita una actualización (memoria, espacio, sistema), te cotizamos la opción más económica para que llegues listo — o te prestamos equipo el día del taller (avísanos con tiempo, hay pocos).
PASO 2 DE 4

Instala Node y Claude Code

Windows
  1. Descarga Node.js (versión LTS) desde nodejs.org/es e instálalo con todo en "Siguiente".
  2. Cierra y vuelve a abrir cualquier ventana negra (terminal) que tuvieras abierta.
  3. Abre una terminal nueva: presiona Windows + R, escribe cmd, Enter.
  4. Pega este comando y presiona Enter (tarda 1-3 minutos):
npm install -g @anthropic-ai/claude-code Mac
  1. Descarga Node.js (versión LTS) desde nodejs.org/es e instálalo.
  2. Abre la app Terminal (Spotlight → escribe "Terminal").
  3. Pega este comando y presiona Enter:
npm install -g @anthropic-ai/claude-code
Nota: no necesitas crear cuenta ni iniciar sesión todavía. El día del taller te damos tu llave de acceso — solo necesitamos que el programa quede instalado.
